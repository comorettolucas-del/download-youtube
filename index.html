⚠️

Se você ainda não instalou o yt-dlp, siga os passos abaixo antes de usar os comandos de download.

1
Abra o Prompt de Comando (CMD)

Pressione Win + R, digite cmd e aperte Enter. Ou pesquise "Prompt de Comando" no menu Iniciar.

2
Verifique o winget

O winget já vem no Windows 10/11. Para verificar, cole no CMD:

CMD
winget --version

Se não funcionar, baixe em: aka.ms/getwinget

3
Instale o yt-dlp

Cole no CMD e aguarde terminar:

CMD — Instalação
winget install yt-dlp
4
Reinicie o CMD

Feche e abra o CMD novamente para que o Windows reconheça o yt-dlp.

5
Verifique a instalação

Cole para confirmar que tudo está certo:

CMD — Verificação
yt-dlp --version
✅

Instalação concluída! Volte para a aba Baixar para gerar seus comandos.
